Stock Portfolio Tracker

Description

Stock Portfolio Tracker is a simple Python project that calculates the total value of stock investments. Users enter stock names and quantities, and the program uses predefined stock prices to compute the investment value.

Features

- User input for stock name and quantity
- Hardcoded dictionary for stock prices
- Calculates total investment value
- Saves results in TXT and CSV files

Technologies Used

- Python
- Dictionary
- File Handling

Project Structure

How to Run

1. Install Python
2. Open terminal
3. Run the program

python stock_tracker.py
